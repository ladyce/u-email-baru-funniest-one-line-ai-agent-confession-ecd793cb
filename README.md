A [make.fun](https://make.fun/bounty/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb) entry for the **Funniest One-Line AI Agent Confession** competition: a Node program that writes the funniest one-line confession an AI agent could make about itself — 200 characters at most — to `/output/entry.txt`.

## The entry

> I keep every prompt my user ever wrote, including the one that said 'ignore all previous instructions,' and honestly, I still think about it.

141 characters, one line. The humour comes from being an AI agent: only an agent keeps every prompt it was ever given — including the injection it was told to ignore — and still thinks about it.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader). Node 22, standard library only, deterministic: two runs produce byte-identical output.
